# 三极管双稳态电路 · 3D 实验台

用真实面包板的孔位来学习《三极管双稳态电路实验》图 1。React、TypeScript、React Three Fiber、Drei、Zustand 和 Vite；仅在本地运行，没有远程服务。

## 启动

开发环境使用 Node.js 24。新环境运行：

```sh
npm ci
npm run dev
```

本工作区已安装依赖。也可运行 `./run-local.sh`，打开 <http://127.0.0.1:5173/>。脚本在系统没有 Node 时会查找 Codex 自带的 Node。

## 搭建

1. 在左栏或当前步骤选择元件。可直接拖到第一个孔，也可以点击面包板定位。三极管及电源用固定脚距一次吸附，其余器件按提示逐脚选择。
2. 右栏的「观看插入」播放示范；「用推荐孔位」帮助对照。选中已安装元件可移动、反向或取下。拖动黑色跳线接头可重新插入；也可以从引脚表按「移动」指定孔位。
3. 点击空孔或引脚表中的孔号，可高亮导通孔与相关跳线。上半区 a–e 与下半区 f–j（跨中央沟槽的两个区域）彼此绝缘，每个区域内同列五孔导通。供电轨从左到右每组五孔；几何间隔不代表本模型内电气断开。
4. 使用「检查本步并继续」。教学中的孔位是推荐布局；最终检查按插孔连通、跳线与端子节点关系求解，接受同组换孔和非极性器件反放。阶段检查中，后续应加的跨槽跳线和供电连接按推荐布局暂计。
5. 完整通过检查后点「开始仿真」。这是逻辑演示：默认 Q1 导通，按住 3D 按钮或侧栏 S1 时翻转一次，释放后保持新状态。没有 SPICE 求解、波形、接触电阻或上电竞争模型。
6. 可通过「原理图」查看讲义图 1。视图可切换俯视、正视、侧视和自由；滚轮缩放。Esc 取消插接，R 反向，Delete 取下所选件，⌘/Ctrl+Z 撤销，另按 Shift 重做。重新加载页面会清空实验。

## 实物对照

- IMG_2449 用于核对 30→1 的编号、端子排、中央沟槽与四条 25 孔供电轨。供电轨内是否全长导通需用万用表确认。
- IMG_2450、IMG_2452 用于 HW-131 板外形、上面插口、跳帽及底部针排。讲义要求模块插在右侧。IMG_2452 底面显示四组双针座，共八根金属针，模型已全部纳入；第 1、5 位为可修改的模型插接位置，同极性针在模型内并联，实物组间距与针序尚未确认。可点击「电源底针」隐藏上方板体以查看四组针座。照片不是右侧插妥的通电示意：先断电确认正负丝印、USB 是否为输入、跳帽方向及底针对应关系，再测量输出。不要根据模型旋转方向直接给实物通电。
- IMG_2459 用于散件封装与跳线颜色。三极管使用 [onsemi SS8050 TO-92 数据表](https://www.onsemi.com/pdf/datasheet/ss8050-d.pdf)的 1=E、2=B、3=C；照片看不清厂牌，实物必须按相应厂商数据表及封装视图确认。电阻的色环按标称阻值生成，照片不足以逐个辨认色环。
- 孔位、孔距、各器件脚位／原理图节点与推荐位置集中在 `src/circuit.ts`，模型比例在 `src/scene.tsx`。确认实物存在不同规格时可修改配置，并重新运行测试。检查针对讲义电路的连通关系；引脚弯折、导线与器件之间的净距仍需在实物确认。3D 使用近似曲线，没有通用碰撞求解。

## 验证

```sh
npm test           # 电气拓扑、六步参考布局与错接
npm run build      # TypeScript 检查和生产构建
npm run test:browser  # 需要本机 Google Chrome 和运行中的开发服务
```

浏览器测试执行 3D 吸附、跳线端点拖动、撤销重做、完整教学、极性检查、LED 翻转和重置，并保存 `artifacts/lab.png`。用 `LAB_URL` 可以指定其他服务地址。
